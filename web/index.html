    02 / RESULTS

    03 / PIPELINE

    Classical eyes. Deep memory.

    Classical computer vision measures and repairs the image, deep networks localise and identify, and a hybrid layer decides what to trust.

      LIMITS

      • Closed set of 196 Stanford Cars classes, mostly US-market cars 1991-2012. Unknown models map to the nearest class: read the confidence.
      • Year is the hardest attribute: some generations look identical.
      • One primary vehicle per photo.

      RESPONSIBLE USE

      • Recognises vehicle types only: no number plates, people or tracking.
      • Photos are processed in memory and never stored.
      • Below the confidence threshold it backs off to a coarser answer instead of bluffing.
